# AI Write

Write long stories with AI that remembers your world: characters, places, lore and style,
so every scene stays consistent.

## Installing (Windows)

Download `AI-Write-Setup-x.y.z.exe` from the latest release on the
[Releases page](../../releases) and double-click it. AI Write then opens from the Start menu.

## For developers

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

```
npm install
npm run dev        # run the app with hot reload
npm run typecheck
npm test
```
