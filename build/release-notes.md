What's new in 0.7.3:

- You can connect your Anthropic API key to use Claude directly. In Settings › Models, choose Add a provider, then Anthropic, and paste your key.
- Set a target for a whole chapter on its chapter card, and see how far it has got ("3,200 of 6,000 words"). Scenes left on Auto share it out.
- Settings › Writing has a default scene length and chapter length, used wherever a scene or chapter doesn't set its own.
- Every draft, and Write the whole chapter, now waits for the memory to finish reading the scenes before it, however long that takes. Variants still go ahead after a minute, and are never read by the memory until you pick one.
