What's new in 0.8.1:

- Talking a plan over now makes the whole change in one go: the AI finds every scene your request affects and changes each one, instead of saying it changed something when it hadn't.
- Only the parts you ask about are rewritten, so changes come back much faster and cost far less.
- The change preview shows just what changed, with the old words struck through, and the whole plan is a click away.
- Saying "not quite" while a change is waiting fixes that change instead of starting over.
- A friendlier chat: clearer messages, a list of what each answer changed, Try again after an error, New talk, and an option to apply changes straight away (with Undo).
