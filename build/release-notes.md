The memory now keeps up with your story by itself.

- As you write, it notes what happens: who lost what, who learned what, what changed. Edit or delete the words and the memory follows.
- Anything you type into the memory yourself is never changed.
- Drafting an earlier scene never tells the AI what happens later.
- "What changed" lists every update, each with Undo.
- Mark a scene done with Ctrl+Enter.
- New pages for groups, items, events, plot threads and a glossary.
- The memory can use a model of its own, in Settings › Models.
